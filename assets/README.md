Place GLB models here (exported from Blender, glTF/GLB):

- `arena.glb` — статичная сцена ринга/бортов. Ориентация: центр в (0,0,0), размер около 16×10 единиц, низкая высота по Y.
- `player.glb` — базовая модель персонажа, клонируется на 4 слота. Ориентация: лицом вдоль +Z. Масштаб: ширина ~2.2, глубина ~0.7.
- `ball.glb` — модель мяча, центр в (0,0,0), радиус ~0.45.

Требования для финальных ассетов:
- Центрируйте pivot в (0,0,0) без смещения.
- Минимум материалов/текстур, без тяжёлых шейдеров.
- Экспорт без анимаций (на Stage 1/2).
