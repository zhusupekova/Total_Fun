# Assets stub

Place GLB models here (exported from Blender, glTF/GLB):

- `arena.glb` — статичная сцена ринга/бортов.
- `player.glb` — базовая модель персонажа (будет клонироваться на 4 слота). Ориентация: лицом вдоль +Z. Масштабируйте так, чтобы по ширине вписывался в 2.2 единицы, а глубина ~0.7.
- `ball.glb` — модель мяча, центр в (0,0,0), радиус ~0.45 единицы.

Требования:
- Центруйте pivot в (0,0,0), без смещения, чтобы позиционирование работало корректно.
- Включите минимальное количество материалов/текстур, без тяжёлых нод/шейдеров.
- Экспортируйте с включёнными нормалями, без анимаций (на Stage 1).

Фолбэк: если файлов нет, игра использует примитивы (бокс/сфера) из `src/main.js`.
