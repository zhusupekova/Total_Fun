# Sound effects

Положите сюда звуки в формате `.ogg` или `.webm` (поддерживаются и `.mp3` как резерв):

- `hit_player.ogg` — удар мяча об игрока.
- `hit_wall.ogg` — удар мяча об борт.
- `goal.ogg` — гол/забитый мяч (зарезервировано).
- `magnet.ogg` — эффект магнитного поля (зарезервировано).

Файлы можно переименовать на `.webm`/`.mp3` — пути в коде нужно будет обновить.
